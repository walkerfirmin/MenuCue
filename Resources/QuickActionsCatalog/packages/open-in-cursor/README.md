# Open in Cursor

Open file or directory in Cursor

## Dependencies

```bash
brew install cursor
```

MenuCue can run this for you when you install the Quick Action (after confirmation).

## How to use

1. Install any dependencies listed above (if any).
2. Select matching items in Finder.
3. Right-click → Quick Actions → **Open in Cursor**, or run it from MenuCue’s palette under Services.
