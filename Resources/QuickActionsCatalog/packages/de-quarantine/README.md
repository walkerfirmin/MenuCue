# De-Quarantine

Removes the `com.apple.quarantine` extended attribute from selected Finder items so macOS Gatekeeper no longer treats them as downloaded from the internet.

## Dependencies

None.

## How to use

1. Select one or more files or folders in Finder.
2. Right-click → Quick Actions → **de-quarantine**, or run **De-Quarantine** from MenuCue’s palette under Services.
3. The quarantine flag is cleared recursively on each selected item.
