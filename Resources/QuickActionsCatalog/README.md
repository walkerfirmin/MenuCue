# MenuCue Quick Actions Catalog

Official and community-style package index for MenuCue’s **Quick Action Repo Manager**.

## Official catalog URL

Published on GitHub Pages (zips generated by CI):

`https://walkerfirmin.github.io/MenuCue/index.json`

Source of truth in git is this directory (`packages/<slug>/*.workflow` + metadata). `workflow.zip` files are **not** committed (see repo `.gitignore`); they are produced by [`scripts/build-quick-actions-catalog.sh`](../scripts/build-quick-actions-catalog.sh) for Pages and for the app’s bundled `Resources/QuickActionsCatalog`.

## Layout

### Source (git)

```text
QuickActionsCatalog/
  index.json
  packages/
    <slug>/
      package.json
      README.md
      <Name>.workflow/     # Automator Quick Action source
```

### Published / bundled (generated)

```text
  index.json
  packages/
    <slug>/
      package.json         # checksum updated to match zip
      README.md
      workflow.zip
```

## `index.json`

| Field | Description |
|-------|-------------|
| `schemaVersion` | Currently `1` |
| `name` | Human-readable catalog name |
| `updatedAt` | ISO date string |
| `packages[]` | Summaries with `id`, `name`, `summary`, `version`, `tags`, `path` |

`path` is relative to the catalog root (the directory that contains `index.json`).

## `package.json`

| Field | Description |
|-------|-------------|
| `id` | Stable unique id (reverse-DNS recommended) |
| `name` | Display name (should match the Services menu title) |
| `version` | Semver string |
| `author` | Author or org |
| `readme` | Relative Markdown file |
| `workflow` | Relative `.workflow` bundle name |
| `workflowZip` | Relative zip of that bundle (usually `workflow.zip`) |
| `dependencies.brew` | Homebrew formula names to install (with user confirmation) |
| `minMacOS` | Minimum macOS version |
| `checksum` | `sha256:<hex>` of `workflowZip` (set by the build script in published output) |

## Authoring a package

### Via Quick Action (recommended)

1. Install the packager once: copy [`Package Quick Action.workflow`](../Package%20Quick%20Action.workflow) into `~/Library/Services/` (or open it in Automator and save as a Quick Action).
2. Build your Quick Action in Automator and save it as a `.workflow`.
3. In Finder, select that `.workflow` → right-click → **Quick Actions** → **Package Quick Action**.
4. Choose your `QuickActionsCatalog` folder (the directory that contains `index.json`).
5. Fill in the prompts (name, id, version, author, summary, tags, brew deps, etc.).

The action copies the workflow into `packages/<slug>/`, can create a local `workflow.zip` + checksum, writes `package.json` and `README.md`, and upserts the entry in `index.json`. Local zips are gitignored; CI rebuilds them for Pages.

### Manually

1. Build a Quick Action in Automator and save it as a `.workflow`.
2. Place it under `packages/<slug>/` with `package.json` and `README.md`.
3. Add a summary entry to `index.json`.
4. Optionally generate zips locally:

```bash
./scripts/build-quick-actions-catalog.sh QuickActionsCatalog /tmp/catalog-out
```

## Publishing (official repo)

On push to `main` (catalog paths), [`.github/workflows/deploy-catalog-pages.yml`](../.github/workflows/deploy-catalog-pages.yml) builds the catalog and deploys to GitHub Pages.

**One-time:** GitHub → Settings → Pages → Source = **GitHub Actions**.

## Community catalogs

1. Put a catalog with the same source layout in a public GitHub repo.
2. Copy the deploy workflow (point `build-quick-actions-catalog.sh` at your catalog folder, or vendor that script).
3. Enable Pages → Source = **GitHub Actions**.
4. In MenuCue → **Quick Action Repo Manager…** → **Add Repository URL…**, paste your Pages `index.json` URL (for example `https://<user>.github.io/<repo>/index.json`).

Only HTTPS indexes are accepted.
