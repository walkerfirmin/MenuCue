# Convert Audio to MP3

Converts selected audio files to MP3 using `ffmpeg`.

## Dependencies

```bash
brew install ffmpeg
```

MenuCue can run this for you when you install the Quick Action (after confirmation).

## How to use

1. Install `ffmpeg` (see above).
2. Select one or more audio files in Finder.
3. Right-click → Quick Actions → **Convert Audio to MP3**, or run it from MenuCue’s palette under Services.
4. An `.mp3` is written next to each source file (same basename).
